# Security Policy

## Supported Versions

Only the latest release on the `master` branch receives security fixes.
Older releases are not updated.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Use [GitHub private vulnerability reporting](https://github.com/imamrasyid/customigniter-3/security/advisories/new)
instead. We will be notified automatically and will work with you on a
coordinated disclosure.

When reporting, include as much detail as you can:

- the affected version or commit
- steps to reproduce the issue
- the potential impact and any known workarounds
